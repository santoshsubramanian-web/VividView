# VividView

VividView is a clean, responsive image-search application designed to help users discover high-quality imagery across various topics. In future updates, it will fetch and render dynamic image results from a public API based on user search queries.

## Design Decisions

1. **Ocean Emerald Theme & Clean Layout**: Chose a crisp emerald tone (`#0d9488`) combined with soft slate backgrounds to provide a modern visual identity that differs from standard reference templates.
2. **Category Quick-Pick Chips**: Added clickable category buttons below the search input to allow users to quickly search common topics with a single click.
3. **Empty-State Messaging**: Included an explicit empty-state element ("Search to see results") to guide first-time users before any search has been performed.
